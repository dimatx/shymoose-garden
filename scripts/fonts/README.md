# Sign fonts

Unmodified Barlow Condensed Bold, Italic, and Regular fonts, by The Barlow
Project Authors, distributed under the SIL Open Font License 1.1 in
[`OFL.txt`](OFL.txt).

Source: [Google Fonts, revision 60824dce48f7dd28fe7d65559f2da1f6e04e585b](https://github.com/google/fonts/tree/60824dce48f7dd28fe7d65559f2da1f6e04e585b/ofl/barlowcondensed).

`gen:3mf` registers these files in a temporary OpenSCAD wrapper with `use`
directives. No system font installation is required. This avoids silently
substituting another font when generating signs on a different machine.
